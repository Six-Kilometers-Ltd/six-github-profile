# Six Kilometers Ltd

An independent software studio in London, United Kingdom, founded in 2025.

We do two kinds of work:

- **Desktop applications for personal productivity**, for the Mac and for Windows. Small, focused tools that do a single job properly and then get out of the way. The first of them are in development.
- **Back-end and integration systems** for a small number of clients: APIs, messaging and middleware, and the operational plumbing that keeps them honest.
